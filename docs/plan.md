# Golden Casino 开发计划

## 一、项目定位

一个轻量级的网页端 **赌场小游戏**,核心追求"打开即玩"的体验,不需要登录、不需要后端。

## 二、首期目标(MVP)

只做 **老虎机(Slot Machine)** 一个游戏,先把玩法跑通,后续再扩展。

### 核心玩法
- 玩家初始拥有 **1000 金币**
- 每次下注固定金额(例如 10 金币),点击"抽奖"按钮
- 3 个转轮独立旋转,停下后显示 3 个图案
- 根据图案组合判定中奖,扣除/增加金币

### 中奖规则(初版)
| 组合 | 倍率 |
|---|---|
| 三个 7️⃣ | ×50 |
| 三个 ⭐ | ×20 |
| 三个 🔔 | ×10 |
| 三个相同(其他) | ×5 |
| 两个相同 | ×2 |
| 全不同 | 0(输) |

### UI 元素
- 标题 / Logo
- 金币余额显示
- 3 个转轮(带旋转动画)
- "抽奖"按钮(余额不足时禁用)
- 中奖弹窗 / 提示文字
- "重置游戏"按钮(把金币重置回 1000)

## 三、技术栈

| 类型 | 选型 | 原因 |
|---|---|---|
| 前端 | 原生 HTML + CSS + JavaScript | 零依赖,打开 `index.html` 就能玩 |
| 持久化 | `localStorage` | 记住余额,刷新不丢 |
| 后端 | 无 | MVP 阶段不需要 |
| 部署 | GitHub Pages | 一键上线 |

## 五、实现步骤

1. **骨架**:`index.html` + `style.css`,把 UI 摆出来(静态,不动)
2. **核心逻辑**:`slot.js` 实现随机转轮 + 中奖判定 + 金币加减
3. **动画**:转轮滚动动画(CSS transform / requestAnimationFrame)
4. **持久化**:用 `localStorage` 存余额
5. **润色**:中奖音效(可选)、视觉反馈(中奖闪烁)
6. **README**:写清楚怎么玩 + 在线地址

## 六、后续可扩展(非 MVP)

- 增加 21 点 / 轮盘 / 骰宝,做成"赌场大厅"
- 每日签到送金币
- 中奖排行榜(需要后端)
- 移动端适配
- 音效与背景音乐开关
